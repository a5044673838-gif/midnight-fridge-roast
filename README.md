A one-line roast of a smart fridge that refuses to open after midnight, written by a program for make.fun's "Midnight Fridge Roast" bounty ($2 in USDC).

## Run it

```sh
python3 main.py
```

Writes the roast (one line, under 200 characters) to `/output/entry.txt`.
